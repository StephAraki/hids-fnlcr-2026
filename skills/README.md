# Skills

- **`imaging-ml-skill/`** — the main deliverable: an AI-assisted radiomics machine-learning workflow
  for NCI Imaging Data Commons (IDC) data. It guides a researcher from a plain-language question to a
  documented, reproducible analysis, and ships a fully worked proof-of-concept notebook. See its own
  [`README.md`](imaging-ml-skill/README.md) and `SKILL.md`.

- **`imaging-ml-skill-workspace/`** — skill-creator evaluation runs for `imaging-ml-skill`: benchmark
  results comparing the skill's behavior with and without the skill loaded. This is evaluation
  evidence, not source code.
