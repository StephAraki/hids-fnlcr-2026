# requirements.txt for imaging-ml-skill (v0.3.0) -- pip alternative to environment.yml.
#
# PyRadiomics 3.0.1 needs NumPy 1.x, an older setuptools, and versioneer at build time.
# Install in this order (a clean venv is strongly recommended):
#
#   python3 -m venv venv && source venv/bin/activate      # Python 3.9-3.11
#   pip install --upgrade pip
#   pip install "setuptools<65" wheel versioneer "numpy==1.26.4"
#   pip install --no-build-isolation -r requirements.txt
#
# Why the pins: numpy<2 (pyradiomics 3.0.1 C extension is NumPy-1.x ABI and will not import
# under NumPy 2.x) and pandas 2.2.x (so idc-index, which needs pandas<=2.2.4, can coexist).
# See references/environment_setup.md for the reproduced failures.
